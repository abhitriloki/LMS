This is a comprehensive Learning Management System designed for modern organizations. Employees can take courses, complete assessments, earn certificates, and receive AI-powered recommendations for their learning journey.

📚 Online Courses

Browse and enroll in a wide variety of courses across multiple categories and difficulty levels

✅ Tests & Quizzes

Complete interactive assessments to test your knowledge and track your understanding

🏆 Certificates

Earn official certificates upon course completion to showcase your achievements

📊 Progress Tracking

Monitor your learning progress with detailed insights and completion statistics

🤖 AI Recommendations

Get personalized course recommendations powered by machine learning algorithms

API Endpoints

The LMS provides a RESTful API for all features:

POST /auth/register - Register a new user
POST /auth/login - Login to the system
GET /courses/ - List all available courses
POST /courses/{id}/enroll - Enroll in a course
GET /assessments/{id} - Get assessment details
POST /assessments/{id}/start - Start an assessment
GET /progress/my-progress - View your learning progress
POST /certificates/generate/{course_id} - Generate a certificate
GET /recommendations/ - Get AI-powered course recommendations

Built with Flask, SQLAlchemy, and scikit-learn

Getting Started: Use the API endpoints above or run the demo script to populate sample data
