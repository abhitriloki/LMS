## 🔧 Troubleshooting Quick Reference

### If Kiro asks about database:
1. Open: `http://localhost:8080/phpmyadmin`
2. Click "New"
3. Name: `corporate_lms`
4. Collation: `utf8mb4_unicode_ci`
5. Click "Create"
6. Tell Kiro: "Database created, continue"

### If Composer fails:
Kiro will automatically try: `composer install --ignore-platform-reqs`

### If npm fails:
Kiro will automatically try: `npm install --legacy-peer-deps`

### If migrations fail:
Kiro will check:
- Database connection
- Database exists
- Credentials are correct

**Kiro handles most issues automatically!**
