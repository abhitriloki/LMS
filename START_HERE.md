## ⚡ Fastest Way to Get Started (Recommended)

### 🤖 Use Kiro Automated Setup

**Total Time:** 8-15 minutes (only 3 minutes of your time!)

**3 Simple Steps:**

1. **Open your project folder in Kiro**
   - Launch Kiro IDE
   - File → Open Folder
   - Select: `C:\wamp64\www\corporate-lms`

2. **Open Kiro chat and paste the setup prompt**
   - Press `Ctrl+L` to open chat
   - Open file: `KIRO_QUICK_SETUP.md`
   - Copy the prompt and paste into Kiro chat

3. **Let Kiro do the work!**
   - Kiro will install everything automatically
   - You'll only need to create the database (takes 30 seconds)
   - Done!

**👉 Open `KIRO_QUICK_SETUP.md` now to get started!**

## ✅ Prerequisites (Check These First)

Before starting any setup method, make sure you have:

- [ ] WAMPP installed at `C:\wamp64`
- [ ] WAMPP running on port 8080
- [ ] Apache service running in WAMPP
- [ ] MySQL service running in WAMPP
- [ ] Project files copied to `C:\wamp64\www\corporate-lms`
- [ ] Composer installed on your system
- [ ] Node.js and npm installed on your system

**Need help with prerequisites?** Check `COMPLETE_BEGINNER_SETUP_GUIDE.md` Section 1
